تحديث إصلاح الرسم البياني – Highfield Egypt Learning Portal

الملفات المطلوب استبدالها في مستودع GitHub:
1) trainee-dashboard.html
2) portal.js

ما تم إصلاحه:
- قبل إنشاء أي رسم بياني جديد، يتم تدمير الرسم السابق المرتبط بنفس عنصر Canvas باستخدام Chart.getChart(...).destroy().
- تحديث رقم إصدار portal.js في صفحة المتدرب لإجبار المتصفح على تحميل النسخة الجديدة.
- لا يتطلب هذا التحديث تفعيل Firebase Storage.

خطوات التركيب:
1) فك ضغط الملف.
2) استبدل الملفين المذكورين في نفس مساراتهما بالمستودع.
3) انتظر اكتمال نشر GitHub Pages.
4) افتح لوحة المتدرب واضغط Ctrl + Shift + R أو افتحها في نافذة خاصة.

ملاحظة: هذا التحديث يعالج خطأ Canvas is already in use فقط، ولا يعيد إرسال أو تعديل أي دفعة مسجلة سابقًا.
