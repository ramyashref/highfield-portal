HIGHFIELD EGYPT — PROGRAM PRICING UPDATE

1) Upload js/program-pricing.js into the repository's js/ folder.

2) Open programs.html and add this line AFTER the existing js/program-catalog.js script:
   <script src="js/program-pricing.js"></script>

3) Open program.html and add this line AFTER the existing js/program-detail.js script:
   <script src="js/program-pricing.js"></script>

4) Commit and push the changes. GitHub Pages will publish the updated pages.

PRICES
- Basic: 2,000 EGP
- Intermediate: 4,000 EGP
- Advanced: 8,000 EGP

AUTOMATIC LEVEL ASSIGNMENT
- Titles containing Advanced or Intensive are Advanced.
- Programs lasting 5 days or more are Advanced.
- Titles containing Basic or Fundamentals are Basic (unless they already matched Advanced).
- Programs lasting 3–4 days are Intermediate.
- Remaining programs are Basic.

IMPORTANT
This is an automatic first-pass classification based on program titles and training days.
Review the assigned levels before publishing, especially long foundational programs and
short specialist workshops, because duration alone may not reflect the intended academic level.
