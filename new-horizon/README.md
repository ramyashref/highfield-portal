# NEW HORIZON — International Pediatric Surgery Conference

Static multi-page conference website for GitHub Pages.

## Pages
- `index.html` — Home
- `speakers.html` — Speakers directory (profiles awaiting confirmed faculty details)
- `agenda.html` — Proposed scientific agenda, including the two scientific days and strategic day
- `workshops.html` — Four proposed workshops on separate days
- `strategic-day.html` — Strategic & Leadership Day
- `sponsors.html` — Partners and sponsors
- `register.html` — Registration request form interface

## Publish
Upload the contents of this `new-horizon` folder into the existing `new-horizon` directory in the Highfield GitHub repository. Keep the folder structure and the `assets` directory intact.

## Before going live
1. The agenda and workshop topics are planning drafts, not approved final content. Confirm them with the Conference President / Scientific Committee.
2. Dates and final venue are intentionally marked Coming Soon.
3. Speaker names, portraits, affiliations, and biographies must be added when confirmed.
4. The registration form currently performs front-end validation only. Connect it to a secure form endpoint or database before collecting real submissions. It is a request for review, not a confirmed booking; there is no online payment.
5. Replace any provisional venue references after official confirmation.
