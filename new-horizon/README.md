# Cinematic AI Surgery — NEW HORIZON

## Files
- `index.html` — page structure and content
- `assets/css/style.css` — visual design, layout, and animations
- `assets/js/main.js` — particles and mouse parallax

## Preview
Open `index.html` in a modern browser. Internet is used only for loading the Google Fonts stylesheet.

## Upload to Highfield
Upload the `index.html` file and the entire `assets` folder to the same directory on your website. Keep the folder structure unchanged.

Example:
```
your-folder/
  index.html
  assets/
    css/
      style.css
    js/
      main.js
```

If uploading into an existing Highfield website, do not replace its main `index.html` unless this is intended to become the homepage. Safer option: upload this folder as a subfolder such as `/new-horizon/`.
